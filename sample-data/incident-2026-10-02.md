# Incident Report: Checkout latency spike (2026-10-02)

- Severity: SEV-2
- Duration: 42 minutes
- Owner: Bob (backend team)

## Root cause

A missing index on `orders.customer_id` after the PostgreSQL 17 migration caused
full table scans during peak traffic.

## Fix

Added the index `idx_orders_customer_id` and a CI check that compares indexes
between the old and new schema before every migration.

## Follow-up

Carol (SRE) added a Grafana alert when p95 checkout latency exceeds 800 ms.
